## 怎么填（速览）

1. 剧情对话文件是 JSON 对象，只认两个键：`"_说明"`（字符串数组，加载器**忽略**，随便写）与
   `"rounds"`（对话轮次数组）。
2. `rounds` 元素格式：`{"speaker": "晷" | "我", "texts": ["句1", "句2", …]}`。
   **合法 speaker 只有两个：「晷」与「我」**，其他值不识别（该轮跳过并控制台告警，不崩）。
3. 同一 speaker 连续多句=合并为一轮多 `texts`，玩家**连点多次**逐句走完再切下一角色；
   来回交替、长度不限。
4. **JSON 文件里不得写注释**（Godot 4.7 解析会失败）——说明一律写进 `"_说明"`。
5. **本目录文件不控制立绘**：对话立绘=晷（主角无立绘，只有名字框，晷框在左、我框在右），
   由游戏内常量按关卡映射定档（第 1 关→开头、第 2 关→宋、第 3 关→元、第 4 关→明、第 5 关→现），
   对话开始定档、对话期间锁死。
6. 气泡文件：`{"_说明": […], "lines": ["句1", "句2", …]}`，纯字符串句子池（消费与抽取归 Y5 波）。

## 填写步骤（正式台词替换 = 零代码，仅改 JSON）

1. 打开对应关卡的 JSON（第 N 关改 `第N关.json`；气泡改 `气泡_第N关.json`）。
2. 保持 `"_说明"` 与 `rounds`/`lines` 结构不动，只替换台词字符串（占位关把 `"_说明"` 里的
   「占位待替换」条目删掉）。
3. 保存为 UTF-8（无 BOM 亦可），运行游戏走到对应对话即可生效，无需改任何代码。
