# 千年一榫

中文 | [English](README_EN.md)

以中国传统木结构营造技艺——**榫卯**（国家级非物质文化遗产）为主题的文化体验 + 休闲益智游戏。

玩家扮演一位**失忆的匠人**，与跨越古今的见证者**「晷」**同行，穿越**河姆渡、宋、元、明、现代**五个时代，亲手从体素化的原始木料中挖除多余部分，复原各式榫卯构件并与固定件对接，一步步找回失落的手艺。

> 引擎 Godot 4.7（gl_compatibility 渲染器）· 平台 Windows · 交互 摄像头手势（普通单目摄像头 + MediaPipe）+ 键鼠

## 五个时代，五件文物

| 时代 | 文物 | 一句话看点 |
|---|---|---|
| 河姆渡（新石器时代） | 榫卯木构件 | 在七千年前的干栏式建筑里，复原华夏最早的榫卯雏形 |
| 宋 | 保国寺瓜棱柱斗拱 | 拆解宋代大殿的瓜棱柱与斗拱，体会大木作的精妙咬合 |
| 元 | 真如寺梁架榫卯 | 走进元代梁架，感受梁枋搭接承托屋宇的结构智慧 |
| 明 | 明式黄花梨圈椅 | 为一把传世圈椅接续椅圈与靠背，领略明式家具的极简之美 |
| 现代 | 参数化木构节点 | 用参数化设计重新演绎榫卯，传统技艺与当代计算相遇 |

## 核心循环

剧情对话 → **三视图观察**（中央木料 + 左上目标成品 + 右上固定件，正交等轴测联动）→ **挖除体素**（划选/点选/删除，支持撤销重做）→ **对接判定**（挖出的形状需与目标无容差全等：平移归一后 24 种旋转 + 24 种镜像共 **48 变换等价判定**，等价判定先于干涉判定）→ **评分结算**（完美 / 良好 / 及格 + 获得天赋值）→ **图鉴解锁**（文物点云模型，可旋转欣赏，附四要点介绍）。

## 特性

- **三视图对照**：中央主视 + 左上目标成品 + 右上固定件，三个正交等轴测视图联动，支持有界拖拽旋转、双手推拉缩放、聚焦模式。
- **见证者「晷」**：全程陪伴的伙伴角色，会随时代更换装扮（皮肤系统），提供引导气泡与剧情对话。
- **锐眼**：天赋值付费提示工具，以红/绿差集高亮显示当前形状与目标的差异。
- **图鉴**：通关解锁文物点云模型（MultiMesh 真点云渲染），附四要点介绍。
- **商店**：天赋值购买「晷」的皮肤（含原创皮肤）。
- **关卡编辑器**：独立 Godot 工程的榫卯关卡编辑器（见 `关卡编辑器/`），配套关卡数据接口规范（见 `技术文档/`）。

## 手势一览（可选，普通单目摄像头即可）

- 竖食指（或两指指尖）移动光标
- 中指悬停单击按钮
- 左手三指删除选中的体素，右手二指滑动减选
- 双手握拳清空选择
- 单手翻转：撤销 / 重做
- 双手推拉：缩放视图
- 有界拖拽：旋转三视图
- 双手翻转 4 次：呼出退出倒数

> 无摄像头时游戏完整可玩（手势相关 UI 置灰）。

## 多语言

游戏支持**简体中文 / English** 界面与剧情切换（设置 → Language），首次启动默认简体中文。

## 快速开始（键鼠游玩）

1. 安装 [Godot 4.7](https://godotengine.org/download/archive/)（标准版即可，无需 .NET 版）。
2. 用 Godot 打开 `游戏项目/千年一榫/project.godot`，按 F5 运行主场景。
3. 首次启动按引导操作即可；全程键鼠可完整通关。

## 快速开始（手势交互，可选）

手势识别为独立 Python 进程（`游戏项目/千年一榫/gesture_runtime/`），游戏通过 UDP 本机回环与之通信：

1. 安装 **Python 3.13**（mediapipe 0.10.x 实证锁定；详见 `gesture_runtime/requirements.txt`）。
2. `pip install -r 游戏项目/千年一榫/gesture_runtime/requirements.txt`（MediaPipe / OpenCV / NumPy）。
3. 游戏内「设置 → 手势」开启手势与摄像头；需普通单目摄像头（内置或 USB 均可）。

> 手势进程与游戏通过本机 UDP（默认 9876/9877/9878 端口）通信，不开摄像头则手势子系统保持待机，不影响键鼠游玩。

## 运行无头测试

工程自带 165 个 Godot 无头测试文件（`游戏项目/千年一榫/tests/test_*.gd`）：

```bash
godot --headless --path 游戏项目/千年一榫 --script res://tests/test_main_menu.gd
```

关卡编辑器工程同理（`关卡编辑器/voxel_level_editor/tests/`）。

## 关卡编辑器与接口规范

- 编辑器支持尺寸分域调整、五槽位关卡管理、实时自动保存、试玩预览；产出五件套关卡数据。
- 关卡数据格式契约见 `技术文档/接口规范_关卡数据.md`，剧情对话与气泡格式见 `技术文档/接口规范_剧情对话.md`。
